# متجر التقنية السريع (QuickTech Store)

تطبيق متجر إلكتروني مبني باستخدام **React + Vite + Tailwind CSS**.

## طريقة النشر والحصول على رابط مباشر عبر GitHub Pages:
1. ارفع جميع ملفات هذا المجلد إلى مستودع (Repository) جديد على **GitHub**.
2. ادخل على **Settings** داخل المستودع، ثم اختر **Pages** من القائمة الجانبية.
3. تحت قسم **Build and deployment** -> **Source**، اختر **GitHub Actions**.
4. خلال دقيقة واحدة سيقوم GitHub ببناء الموقع تلقائياً وإعطائك الرابط المباشر (Live URL).
